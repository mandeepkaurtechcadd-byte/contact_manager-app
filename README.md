# Contact Manager App

## About the Project
Contact Manager is a web application developed using Python and Flask. It helps users manage contact information efficiently.

## Features
- Add new contacts
- View contact details
- Update existing contacts
- Delete contacts
- Simple and user-friendly interface

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite 

## Installation

1. Clone the repository:
   `git clone https://github.com/mandeepkaurtechcadd-byte/contact_manager-app.git`

2. Open the project folder:
   `cd contact_manager-app`

3. Install dependencies:
   `pip install -r requirements.txt`

4. Run the application:
   `python app.py`

5. Open your browser and visit:
   `http://127.0.0.1:5000`
